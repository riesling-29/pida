## 최소 재현과 기대

- 비공개 데이터 없는 input: host-bound principal `owner`, logical agent `main`, scope `test-workspace`; synthetic persona text; one synthetic model/result artifact reference with SHA-256 digests.
- 실제 consumer 호출: `resolveContext(request)` returns selected text plus binding/context revision/digest; Pida sends that exact text through Pi. `appendAnalysis({...request, expectedRevision, idempotencyKey, record})` appends only references and an explicitly classified interpretation into existing local experience memory.
- 실제 output: local append receipt includes `appended|duplicate`, record ID/revision and new context revision. A later actual Pi request contains the stored references. No external Persona endpoint was called.
- 기대 producer 의미: stable persona identity; principal/agent/workspace/purpose scope checked before selection; one authoritative snapshot with revision, renderer, content digest and omissions; idempotent CAS append of analysis references; separate WorkingState transition request preserving causal parents and host execution-phase reference.
- WorkingState mapping: current local `AgentMemoryStore.transition` already implements expected head, explicit branches/merges and conflict disposition. External transitions must adapt the producer's versioned equivalent; Pida must not use a local mirror as a second canonical writer.
- Behavior model mapping: model kind (`empirical|aspirational|mandatory`), immutable model/result refs and digests, training/evaluation snapshot refs, cohort/scope, interpretation provenance and activation policy need producer-owned mapping. An experience append is not policy/model activation.
- 정상 case: authorized selection → exact selected input → host inclusion receipt → allowed append → later selected context.
- 실패/권한 case: foreign principal/agent/scope, stale head/revision, changed payload for the same idempotency key, invalid digest/ref, unavailable append capability, missing/expired grant. Reject without writing either local or external canonical state.
- 동시성/호환 case: competing appends from same revision, replay after restart, producer revision changing after context selection, bounded projection omissions, renderer/schema upgrade, unknown fields. Do not silently drop unsupported fields.
- 직접 확인 결과: real local memory/Pi synthetic fixtures exercise scope, CAS/dedupe/restart, revision pinning, converter omission and actual later input visibility. Producer interoperability and live model use: **NOT_RUN**.

- fallback 및 손실: built-in Pida memory is the explicitly selected local authority. It stores source-backed analysis references as `agent-report` experience, without external Persona registry activation. External provider selection disables local canonical writer paths; absent external capabilities remain unsupported.
- 차단 경로: actual PersonaSubstrate cross-host identity/context/WorkingState/model-registry integration and producer-specific acceptance.
- 계속 가능한 Pida 작업: actual PIX calculation/artifact evidence, bounded local skills, host context receipt, local memory CAS and next-run consumption.
- 필요한 합의/artifact: producer schema/version, binding/scope rules, exact context renderer/digest and omitted fields, WorkingState transition response, analysis/model-reference append/activation distinctions, idempotency/CAS errors, normal/denied/conflict/restart fixture bundle.
