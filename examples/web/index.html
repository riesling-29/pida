작업 공간에 연결

로컬 실행 명령의 브라우저 열기를 이용하거나 접속 토큰을 입력하세요.

지금은 데모 모드입니다. LOT-001 또는 LOT-002를 요청하면 합성 데이터를 조회합니다. 자유로운 대화와 내 도구 사용에는 실제 모델을 연결해주세요.

모델 연결 · 설정

프로바이더를 선택하고 API 키와 사용할 모델을 설정하세요. API 키는 서버에만 저장하며 브라우저에 다시 표시하지 않습니다.

고급 설정

초기값은 보수적인 설정값입니다. 서버 모델의 실제 한도에 맞게 조정하세요.

짧은 테스트 응답을 요청합니다. 유료 API는 소량의 요금이 발생할 수 있습니다. 대화 실행 중에는 설정을 바꿀 수 없습니다.

작업 파일 · 결과물 · 저장된 스킬

내 대화들이 함께 사용하는 작업 공간입니다. 파일 생성 → JavaScript 실행 → 테스트·수정 → 스킬 저장을 챗으로 요청할 수 있습니다.

실제 모델 연결이 필요합니다. 실행은 QuickJS JavaScript 전용이며 HTML 미리보기는 정적 화면입니다.
